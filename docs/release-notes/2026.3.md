## [2026.3] - 2026-11-14

### Added

- Beekeeper for iPhone and iPad.
- Hive advertises itself on the local network with Bonjour, so nearby devices find it.
- Pairing by scanning the QR code with the camera.
- Hive emails 14 days, and again at 3 days before the TestFlight of Beekeeper on an iPhone or iPad expires.
- The device list shows each device’s Beekeeper build and when it expires.

### Changed

- A Hive’s overview uses the same grouped layout as its server and job pages.
